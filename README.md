# Courses Kit Lite — free Expo course website template

A free, editorial course/coaching site for **iOS, Android and web from one codebase**, built with
Expo Router, NativeWind (Tailwind), Zustand and TypeScript. Bilingual (English / Spanish).

**Includes:** video hero home page (manifesto, programs, how it works, instructor, testimonials, FAQ,
waitlist form), course catalog, and course detail pages with the full curriculum.
Frontend only — sample data lives in `src/constants/demoData.ts`, backend calls in `src/services/`.

Demo brand: *Cocina Viva*, a fictional cooking school.

## Quick start

```bash
npm install
npx expo start      # press w for web
```

Brand, copy and FAQ: `src/constants/config.ts` · Colors: `tailwind.config.js` · Text: `src/constants/strings.ts`
